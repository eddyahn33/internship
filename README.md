### Git 사용법 공부

#### 명령어
git add 파일명 : Staging 단계에 추가
git commit -m "commit message" : 변경사항을 repository의 timeline에 추가
git push origin master : Github에 변경사항 push

#### Git 환경 정리
src/internship에 인턴십 때 사용하는 모든 .py 및 데이터 파일들 넣기.
/complete : 기타 완성된 코드
/rosalind : rosalind 코드 및 파일
/etc : 기타 작성중인 연습 코드 및 짜투리 파일

/tutorial_evolution : 듀토리얼 프로젝트 '진화의 시작'
